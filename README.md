# Canvas to Pitch Studio

หน้าเว็บสำหรับต่อยอด Concept Card และ Business Model Canvas (BMC) ไปจนถึงการ pitch แบ่งเป็น 5 แท็บ

1. **ข้อมูลของฉัน** วาง Concept Card, BMC, positioning และสรุปการตลาดไว้ครั้งเดียว prompt ในแท็บอื่นจะดึงไปใช้ให้เอง
2. **Prompt เรื่องราว BMC และการตลาด (S1–S2, M1–M7)** ได้แก่ ปัญหา insight และนวัตกรรม (Ten Types) · ตรวจ BMC ให้ครบและสอดคล้อง · STP และ persona · positioning statement (POP/POD, perceptual map) · คู่แข่ง SWOT และ TOWS · 4P/7P กับการตั้งราคา · customer journey · แผนการตลาด Insight → Plan → Implement → Control · ขนาดตลาด TAM/SAM/SOM แต่ละ prompt มีป้ายบอกว่าใช้กับสไลด์หน้าไหนในแม่แบบ pitch
3. **สมมติฐานการเงิน (F1)** ให้ AI ตอบเป็นบรรทัด `key = value` แล้ววางกลับ ระบบจะเติมตัวเลขลงแบบจำลองให้
4. **จำลองการเงิน** แบบจำลองรายเดือน 60 เดือน (5 ปี) ได้งบกำไรขาดทุน งบกระแสเงินสด และงบแสดงฐานะการเงิน (มีการตรวจความสมดุล) ตัวชี้วัดหลัก กราฟ 4 แบบ และสถานการณ์ฐาน ระวัง ดี ส่งออกเป็น PDF หรือคัดลอกงบเป็นตารางไปวางใน Excel ได้
5. **แผนธุรกิจ & Pitch (P1–P4, B1–B3)** P1–P4 เติมเนื้อหาที่สไลด์ต้องมี (การดำเนินงาน พาร์ทเนอร์ กฎระเบียบ · unit economics ความต้องการเงินทุน และแผนใช้เงิน · หลักฐาน ความเสี่ยง แผน 3–6–12 เดือน และสิ่งที่ขอ · ความรับผิดชอบ บันทึกการใช้ AI และแหล่งอ้างอิง) ส่วน B1 ใช้ร่างแผนธุรกิจ 12 หัวข้อ B2 วางเนื้อหาลงแม่แบบสไลด์ pitch 17 หน้าตามเกณฑ์ 15 คะแนน และ B3 ตรวจร่างก่อนส่ง โดย prompt ใส่สรุปจากแบบจำลองการเงินให้อัตโนมัติ ทุกอย่างเป็นร่างแรกที่ต้องเกลาต่อ

## วิธีใช้

เปิด `index.html` ในเบราว์เซอร์ หรือเปิด GitHub Pages ของ repo นี้ (Settings → Pages → Deploy from branch → `main` / root)

หน้าเว็บโหลด Chart.js, jsPDF และ html2canvas จาก cdnjs จึงต้องต่ออินเทอร์เน็ต

## ข้อมูลและข้อจำกัด

- ข้อมูลที่กรอกเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ได้ส่งไปเซิร์ฟเวอร์ใด
- ตัวเลขตั้งต้นในแบบจำลองเป็นตัวอย่างสมมติ (กรณีพลอย) ต้องแก้เป็นของตัวเอง
- แบบจำลองนี้ทำแบบง่ายเพื่อการเรียนรู้และการ pitch เบื้องต้น ไม่คิดสินค้าคงคลัง เจ้าหนี้การค้า และภาษีมูลค่าเพิ่ม ส่วนภาษีเงินได้ใช้อัตราเดียว ก่อนตัดสินใจลงทุนจริงควรให้นักบัญชีตรวจ
- ห้ามใส่สูตรจริง ข้อมูลที่ยังไม่เผยแพร่ ข้อมูลผู้ป่วย หรือเอกสารลับของพาร์ทเนอร์ลงใน AI สาธารณะ

## ส่งออกผลงานเป็น Word

ปุ่ม “ส่งออกผลงานทั้งหมด (Word)” ในแท็บ 5 และปุ่ม “ส่งออก Word” ในแท็บ 4 สร้างไฟล์ .docx ในเบราว์เซอร์ (ใช้ JSZip) ตาม CI คณะเภสัชศาสตร์ มธ. มีโลโก้ที่หัวกระดาษ หัวข้อสีแดงธรรมศาสตร์และเส้นทอง ตารางหัวสีน้ำเงิน และเลขหน้าที่ท้ายกระดาษ เนื้อหาประกอบด้วยข้อมูลที่กรอกไว้ทุกช่อง (ช่องว่างจะไม่แสดง) BMC แบบตาราง 9 ช่อง ตัวชี้วัด สมมติฐาน งบการเงิน 5 ปี และกราฟ ฟอนต์ที่ตั้งไว้คือ Sarabun และตั้งภาษาไทย (th-TH) ให้ทุกข้อความ ถ้าเครื่องไม่มีฟอนต์ Sarabun ให้ติดตั้งจาก Google Fonts
